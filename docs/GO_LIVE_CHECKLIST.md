## 二、上线 6 步

### 第 1 步 · 建 Supabase 项目（~5 分钟，纯点）
1. 进 supabase.com → **New project**
2. **区域必须选 `ap-southeast-1`（新加坡）** —— 建完不能改，选错要整个重建
3. 项目名随便（如 `shichuang`），设个数据库密码并记好
4. 等 1–2 分钟建好

### 第 2 步 · 建数据库表（~15 分钟，粘贴 SQL，不用装任何工具）
1. 进项目 → **SQL Editor** → New query
2. 把 `supabase/migrations/` 里 `0001` 到 `0029` 共 **29 个文件**的 SQL **按顺序依次粘贴执行**（顺序不能乱）
3. 执行完 = 表、权限规则(RLS)、提示词种子、教材版本/知识点表 全部就绪
4. ⚠️ 本机没数据库，**RLS 权限规则还没真机实测过**；上线第一周留意"别人能不能乱改你的数据"，有异常我马上修

> 📌 **2026-09-14 更新**：迁移已从 0017 涨到 **0029**，新增的 `0023`–`0029` 共 7 个必须一起跑，否则下面这些**全部不会生效**：
>
> | 迁移 | 不跑会怎样 |
> |---|---|
> | `0023_3d_scope` | 3D 课件继续出假模型（sin·cos 曲面 / 蓝方块+橙球） |
> | `0024_doc_prompt_fix` | 提示词打架 → 生成失败率高；教案仍是"骨架" |
> | `0025_generation_guardrails` | 月度阀仍是 ¥100（约 3300 次就全站停服）；"整学期"不拦截 |
> | `0026_chart_block` | PPT 继续没有图（只有"建议配图：XX"文字） |
> | `0027_geometry_kernel` | 3D 标注数值仍由 AI 编（可能算错） |
> | `0028_lesson_plan_higher_order` | 教案不标认知层级、无高阶占比、无互动设计 |
> | `0029_credit_cost_double` | 积分仍是旧价（教案 2 分而不是 4 分），赠送成本控制失效 |

### 第 3 步 · 填密钥（~5 分钟）
1. 项目 → Settings → API，复制 **Project URL** 和 **anon key**
2. 项目 → Settings → **Secrets**（Edge Functions 用的），填：
   - `DEEPSEEK_API_KEY` = 你的 DeepSeek Key
   - `TAVILY_API_KEY` = （可选）Tavily Key
3. 前端 `.env` 填 Supabase URL / anon key（我给你模板文件）

### 第 4 步 · 部署后端函数（~10 分钟，最"技术"的一步）
- **首次上线**：部署 `generate` 和 `serve-app` 两个 Edge Function
- **以后再改代码**：只有动了 `supabase/functions/` 下的代码才需要重新部署。2026-09-14 这批改动**只需重新部署 `generate` 一个**（因为新增了 3D 几何内核）
- 需要跑一条命令（我给你写好）；**如果你不想碰终端，我做成"一键脚本"你双击运行**
- 这是整条上线里唯一要动终端的地方，我会把命令压到最少

> 💡 **一句话记住**：**改提示词文案 = 改表即生效，不用部署**；**改后端代码 = 要重新部署 `generate`**；**改界面 = 要重新构建发布前端**。
> 你是非程序员，这条能省掉你以后 90% 的"改个字还得找人上线"。

### 第 5 步 · 部署前端（~10 分钟）
- 本地 `npm run build` 生成静态文件 → 推 GitHub → 开 GitHub Pages（你熟，之前就这么发）
- 或我帮你配**自动部署**：以后改代码推一下就上线，不用每次手动传

### 第 6 步 · 验证（2026-09-14 版：必做这 4 条）
1. 打开线上地址 → 注册（演示模式：任意邮箱 + 密码≥8位 + 邀请码 `SC50`）
2. 生成一份教案 → 导出 PPT / Word → 看排版
3. 给一位老师发链接，看 ta 能不能打开、能不能改
4. **本批次新增的 4 个验证点**（每条都对应上面跑的迁移，不做等于白跑）：

| # | 操作 | 应该看到 | 没出现说明 |
|---|---|---|---|
| 1 | 生成"九年级数学 二次函数图像与性质 第1课时"的 **3D 课件** | 只有几何体/分子，**或**橙色「暂未支持」提示 + 完整文字讲解 | 若仍是蓝方块+橙球 / sin·cos 曲面 → 0023 或 0027 没跑 |
| 2 | 输入"帮我生成九年级数学整学期的教案" | **秒回**"一次只能生成一节课"，且**积分不变** | 若照常生成 → 0025 没跑，或 generate 没重新部署 |
| 3 | 生成一份 PPT | 课件里有**真正的函数图像**（图，不是文字） | 若只有"建议配图：XX" → 0026 没跑 |
| 4 | 生成一份教案 | 顶部有**「高阶活动占比 XX%」大数字**，每环节旁有层级标签（分析/评价/创造是实色） | 若没有 → 0028 没跑，或前端没重新发布 |

> 🎬 **第 4 条那个画面，就是你抖音第一条视频要截的图。**
>
> 🔬 **顺手验一下数学保命项**：跑一个圆柱体（半径 3、高 5）的 3D 课件，看是否显示 `体积 V = πr²h ≈ 141.37`。这是"数学不算错"那套逻辑的直接验证。

### 第 7 步 · 挂一条每日定时任务（建库后必做，~1 分钟）
积分过期逻辑（`void_expired_credits`）目前**没有任何调度在调它**。过期积分老师其实花不出去（不会多花钱），但老师明细里看不到"已过期"这一条，对账缺一环。

在 **SQL Editor** 里先手动跑一次确认不报错（新库应返回 `0`）：
```sql
select public.void_expired_credits(null);
```
再挂每日调度（每天新加坡时间 11:17）：
```sql
create extension if not exists pg_cron;

select cron.schedule(
  'void-expired-credits-daily',
  '17 3 * * *',
  $$select public.void_expired_credits(null);$$
);
```
查看 / 取消：
```sql
select * from cron.job;
select cron.unschedule('void-expired-credits-daily');
```
