## 结论

OpenMAIC 允许修改、商用和再发布，合规前提是保留其版权和 MIT 许可声明。
但本仓库不能直接替换或整仓合并 OpenMAIC，原因是两者运行时边界不同：

| 维度 | OpenMAIC | 师创 |
|---|---|---|
| Web 框架 | Next.js 16 | Vite 5 + React 18 |
| UI 运行时 | React 19 + Tailwind 4 | React 18 + MUI 6 + Tailwind 3 |
| 生成编排 | LangGraph / 多智能体 | Supabase Edge Function + SSE 分段续跑 |
| 内容模型 | Slide DSL / Stage DSL | DocModel / Slide |
| 编辑与导出 | 自有 DSL 编辑器与渲染器 | TipTap / 轻量 SlideEditor + pptxgenjs |

直接搬迁会触发本项目明确禁止的 React、Vite、Tailwind 大版本升级，并让现有
DocModel、在线编辑和 PPTX 导出全部失去共同真相源。因此本阶段采用“借鉴架构、
独立实现”的方式，不 vendor OpenMAIC 的大型运行时包。

## 已吸收的能力

### 1. Plan → Scene 两阶段生成

生成 PPT 前先构建稳定的课程施工图：

- 显式页码、Markdown 标题、项目符号和段落大纲都能解析为页面计划；
- 每页冻结标题、教学功能、版式、覆盖点、视觉表达和课堂动作；
- 大纲页数保持不变，超出上限时合并而不是丢弃；
- 短大纲自动补齐学习目标、总结、作业和必要的课堂环节；
- 每个三段请求只接收对应页面的详细施工图，减少全量长大纲重复注入。

实现位置：`supabase/functions/_shared/doc/pptPlan.ts`

### 2. Slide Craft 页面规则

分段提示词加入页面级硬约束：

- 一页只承担一个教学功能；
- 标题不写教师口播长句；
- 投屏文字优先关键词、步骤、例子和结论；
- 流程用有序列表，对比用表格或双栏，关键概念用 callout；
- 文字过载时先删冗余，不靠缩字号或增页面；
- 演讲者备注必须包含追问、学生活动或常见错误提醒。

### 3. 页面 DSL 的可编辑性

在线编辑增加页面版式切换：

- 自动识别；
- 封面；
- 内容；
- 双栏 / 对比；
- 章节过渡。

版式字段仍写入原有 `Slide.layout`，因此网页预览、版本保存和 PPTX 导出继续共用
同一份 DocModel，无需新增数据库表或修改迁移。

## 暂不直接接入的部分

### 多智能体课堂与 TTS

OpenMAIC 的 AI 教师、AI 同学、LangGraph 导演图和 28 种课堂动作是独立产品形态，
需要实时事件总线、TTS、白板动作和长时间会话存储。它们不适合直接塞进当前
“生成 → 编辑 → 导出”的单次任务链路，应作为后续独立模块评审。

### Slide DSL 与完整编辑器

OpenMAIC 的 Slide DSL、ProseMirror 编辑器、快照渲染器和导出器是一个完整垂直栈。
当前仓库已有 DocModel、在线编辑和 PPTX 导出闭环，直接替换会扩大回归面。
本次只吸收其设计法则与页面施工图，不替换数据模型。

### 自包含交互 HTML

可作为下一阶段能力：在现有 `courseware_2d` 或 PPT 导出菜单中增加“交互课堂 HTML”。
实施前需要先确定 iframe、安全沙箱、体积限制和移动端播放策略。

## 后续可扩展路线

1. 将施工图暴露给前端，在生成前提供可编辑的页面计划确认；
2. 为每页增加“教师动作”结构化字段，驱动自动朗读和课堂播放；
3. 引入多智能体事件总线，但保持生成导出链路与课堂播放链路解耦；
4. 在导出菜单增加自包含交互 HTML，继续保留 PPTX 离线交付；
5. 对真实教师大纲建立回归集，比较页面覆盖率、重复率和编辑次数。

## 合规

当前实现为面向师创 DocModel 的独立代码，没有复制 OpenMAIC 的运行时源码。
若后续直接复制其代码、提示词模板或渲染器，必须先保留 MIT 许可文本、版权声明，
并在 `THIRD_PARTY_NOTICES.md` 中逐项登记。
