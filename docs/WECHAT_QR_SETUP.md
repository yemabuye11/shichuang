# 收款码配置说明（给野马老师 / 管理员看）

> 这份文档是给**不懂技术**的人看的。全程只需要：微信点几下 → 拿到一张图 → 把图变成一个网址链接 → 粘到后台 → 保存。
> 每一步都写了「点哪里」，照着做就行。

---

## 先说清楚一件事（很重要）

师创的充值方式是**线下人工充值**：

1. 老师在「自助充值」页看到你配的**收款码图片**；
2. 老师用微信扫这张码，**给你转账**；
3. 老师点「我已付款」，提交转账凭证；
4. 你（管理员）在后台「待充值」里核对，**手工给老师加积分**。

所以：

- ✅ 后台填的只是**一张图片的网址**，用来「把收款码展示给老师看」；
- ❌ 系统**不会自动收款**、**不会自动加积分**，这是我们的商业模式（不做在线支付），不是坏了；
- ❌ 不需要、也不要去申请微信支付商户号、不要接任何支付接口。

---

## 第 1 步：在微信里生成你自己的收款码

1. 打开手机上的**微信**；
2. 点右下角 **「我」**；
3. 点 **「服务」**（旧版本叫「支付」）；
4. 点左上角/顶部的 **「收付款」**；
5. 点 **「二维码收款」**；
6. 屏幕上就会出现你的收款二维码，点下方的 **「保存收款码」**；
7. 这张图会存到**手机相册**里。

> 小提示：如果想设置固定金额，可以在「二维码收款」页面点「设置金额」，但一般**不要设置**，让老师自己填金额更灵活。

现在你需要把手机相册里的这张图**传到电脑上**（微信文件传输助手、QQ、数据线都行），下一步要用。

---

## 第 2 步：把这张图片变成一个 `https` 开头的图片链接

老师端的网页是没法直接读你电脑里的图片的，它只能读**网上的一个地址**。
所以我们要把这张图传到网上，拿到一个以 **https://** 开头的网址。

下面给你 **3 种做法，选一种就行**（推荐做法一，最稳）。

### 做法一：传到师创自己的空间（Supabase Storage）—— 推荐，链接永远不会失效

1. 打开浏览器，登录 Supabase 后台：https://supabase.com/dashboard
2. 进入师创这个项目；
3. 左侧菜单点 **Storage**（一个文件夹图标）；
4. 如果还没有「桶（bucket）」，点右上角 **New bucket**：
   - Name 填：`public`
   - 把 **Public bucket** 这个开关**打开**（一定要打开，否则老师看不到图）
   - 点 **Create bucket**
5. 点进 `public` 这个桶，点 **Upload files**，选择你刚存下来的收款码图片，上传；
6. 上传完成后，**点一下这个文件的名字**；
7. 右侧会弹出文件信息，里面有一行 **Get URL**（或者一个「复制」按钮），点它复制；
8. 复制出来的就是图片链接，长这个样子：
   ```
   https://xxxxxxxx.supabase.co/storage/v1/object/public/public/wechat-qr.png
   ```
   ✅ 以 `https://` 开头 —— 这就是我们要的链接。

### 做法二：用免费图床（最快，不用登录 Supabase）

推荐用 **ImgBB**（免费、不用注册也能传）：

1. 打开 https://imgbb.com
2. 点页面上的 **「开始上传」**（Upload），选择你的收款码图片；
3. 上传完成后，右侧找到 **「嵌入代码」→「直接链接 / Direct link」**；
4. 复制那个以 `https://i.ibb.co/...` 开头的链接。

> 注意：一定要复制 **Direct link（直接链接）**，不要复制「网页地址」，网页地址是打不开图片的。
> 如果你已经有一个能打开的公开图片网址（比如公司官网上的图片），直接复制它的地址也行。

### 做法三：你已经有一个能访问的图片链接

比如你们学校官网、公众号素材库里已经有一张收款码图片，右键图片 → 「复制图片地址」，
只要是以 **https://** 开头、在浏览器里能直接打开看到图，就可以直接用。

---

## 第 3 步：回到师创后台，把链接填进去

1. 用**管理员账号**登录师创网站；
2. 右上角头像 → 进入**管理员后台**（路径一般是 `/admin`）；
3. 顶部一排标签，点 **「收款码配置」**；
4. 你会看到三个输入框：

   | 输入框 | 填什么 | 例子 |
   |---|---|---|
   | 收款码图片链接 | 第 2 步复制的那个 https 链接 | `https://xxx.supabase.co/.../wechat-qr.png` |
   | 标题 | 显示在图片上方的几个字 | `扫码充值` |
   | 提示语 | 显示在图片下方的一句话 | `转账后请联系管理员加积分` |

5. 填完往下看，有个 **「预览」** 区，能直接看到图片长什么样；
   - 如果预览里显示「这张图片加载不出来」，说明链接不对，回去检查第 2 步；
6. 点右下角 **「保存」**；
7. 页面提示「收款码配置已保存」就成功了。

> 注意：图片链接**必须是 `https://` 开头**。如果是 `http://` 开头，保存会失败（浏览器会拦截不安全图片）。

---

## 第 4 步：验证老师端能不能正常显示

1. 退出管理员账号，用一个**普通老师账号**登录（或者用另一个浏览器开个无痕窗口）；
2. 进入 **「自助充值」** 页面（个人中心里点「自助充值（扫码付款，管理员核对到账）」）；
3. 页面顶部应该能看到：
   - 你填的**标题**（如「扫码充值」）；
   - 中间是那张**收款码图片**；
   - 下面是你填的**提示语**；
   - 最下面一行小字：「这是线下人工充值…系统不会自动到账」。
4. 拿手机微信扫一下这张图，确认能正常识别出你的收款码、能付款；
5. ✅ 到这里就配好了。

如果还没配（或者链接留空），老师端**什么都不显示**，也不会报错、不会有破图——这是正常设计。

## 常见问题

### Q1：图片不显示 / 显示「加载不出来」怎么办？

按顺序排查：

1. **链接是不是 `https://` 开头**？`http://` 会被浏览器拦截；
2. 把链接**直接粘到浏览器地址栏**里打开，看能不能看到图片：
   - 打不开 → 链接错了，重新复制一次（做法一复制 `Get URL`，做法二复制 `Direct link`）；
   - 能打开，但网页上还是不显示 → 多半是**防盗链**（某些图床不让别的网站引用）。换成做法一（Supabase Storage）最稳；
3. 如果用的是做法一，检查那个桶是不是 **Public（公开）**：
   Storage → 点桶名 → 确认是 Public；不是的话在桶的设置里改成 Public；
4. 换浏览器 / 用无痕窗口再试一次（排除缓存问题）。

### Q2：我要换收款码了，怎么改？

不用重新建任何东西：

1. 微信里重新生成、保存新的收款码图片；
2. 把新图上传，拿到新的 https 链接；
3. 后台「收款码配置」→ 把「收款码图片链接」换成新链接 → **保存**；
4. 老师端刷新一下就是新图了。

（旧的那张图片文件可以不管，不影响使用。）

### Q3：为什么老师付了钱，积分不会自动到账？

**因为我们是线下人工充值，这是故意的。**

老师在网页上看到的只是一张**图片**，系统不知道谁扫了、付了多少。流程是：

- 老师扫码转账 → 点「我已付款」提交凭证；
- 你在后台 **「待充值」** 里看到这条申请，核对微信/支付宝账单；
- 确认收到钱了，点**「确认到账」**，积分才会加到老师账号上。

这样做的好处：**零手续费、不需要支付资质、不会有支付合规风险**。

### Q4：能不能自动加积分？

按现在的商业模式**不做**。如果要做，就需要申请微信支付商户号、签支付协议、交手续费，还要处理退款和投诉，目前不划算。保持「线下转账 + 手工加积分」就行。

### Q5：保存时提示「图片链接必须以 https:// 开头」？

说明你粘的链接不是 https 开头。常见情况：

- 粘成了网页地址（如 `imgbb.com/xxxx`）而不是图片地址（`https://i.ibb.co/xxxx.png`）；
- 链接前面多了空格 —— 重新复制一次，前后不要带空格；
- 链接是 `http://` —— 换成 https 的图床重新传。

### Q6：微信收款码会不会过期 / 失效？

不会。微信的个人收款码是长期有效的。
除非你自己换了微信号，那就按 Q2 换一张图。

### Q7：一张图能同时收微信和支付宝吗？

不能。「收款码配置」只放**一张**图。
如果你两种都要，可以在**「收款设置」**这个 Tab 里分别填微信收款码链接和支付宝收款码链接，老师端会并排显示两张。

---

## 一句话回顾

> 微信里保存收款码 → 传到一个能公开访问的地方拿到 https 链接 →
> 后台「收款码配置」粘贴链接 + 标题 + 提示语 → 保存 →
> 用普通老师账号去「自助充值」页看一眼有没有显示出来 → 搞定。
