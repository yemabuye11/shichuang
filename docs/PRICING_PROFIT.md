## 二、那个"半价"政策到底是什么（DeepSeek 峰谷定价）

### 2.1 政策原文要点

| 时间 | 事件 |
|---|---|
| 2026-08-17 00:00 | DeepSeek 首次启用**峰谷分时计价**，API 结构性调价 |
| 2026-08-23 00:00 | 优化：**周六、周日全天不再区分峰谷，统一按低谷价计费** |

### 2.2 时段划分

| 时段 | 时间范围 | 价格 |
|---|---|---|
| **高峰** | 工作日 09:00–12:00、14:00–18:00 | 原价（贵） |
| **空闲（谷段）** | 工作日 00:00–09:00、12:00–14:00、18:00–24:00；**周六周日全天**；**法定节假日全天** | **高峰价的 50%** |

> 简单说：**一天 24 小时里，工作日有 17 小时是半价；周末 48 小时全是半价。**
> 加权平均：**约 79% 的时间处于半价时段**。若教师行为更集中在晚上和周末，实际占比可达 **85–90%**。

### 2.3 V4-Flash 具体价格（师创主力模型）

| 计费项 | 高峰时段 | 空闲时段（半价） |
|---|---|---|
| 输入（缓存命中） | ¥0.10 / 百万 token | **¥0.05** / 百万 token |
| 输入（缓存未命中） | ¥3.00 / 百万 token | **¥1.50** / 百万 token |
| 输出 | ¥9.00 / 百万 token | **¥4.50** / 百万 token |

> ⚠️ 注意：本次调价是**涨价**（8月17日后生效）。V4-Flash 输出从原 ¥2/M 涨到高峰 ¥9/M（+350%）、空闲 ¥4.5/M（+125%）。所以**必须错峰**，否则成本翻好几倍。

### 2.4 为什么这对师创是"量身定做"

教师的行为特征 vs DeepSeek 的定价设计，**高度吻合**：

| 教师行为 | 落在哪个时段 | 价格 |
|---|---|---|
| 白天 9–12、14–18 上课（几乎不生成） | 高峰 | 贵（但用得少） |
| 晚上 18:00–24:00 备课 | **空闲** | **半价** ✅ |
| 午休 12:00–14:00 抽空生成 | **空闲** | **半价** ✅ |
| **周末全天备课**（教师最集中的备课时间） | **空闲** | **半价** ✅ |
| 寒暑假/节假日 | **空闲** | **半价** ✅ |

**结论：师创不需要任何额外改造，绝大部分请求天然就落在半价区间。** 如果再叠加"非实时任务排队到夜间"的调度，还能把剩余的高峰请求也挪到半价。

### 3.1 关键判断

**价格数字三家几乎一样（峰 ¥3/¥9、谷 ¥1.5/¥4.5），真正的差别在"半价窗口的宽度"：**

```
DeepSeek 官方  ████████████████████  79% 的时间半价（含周末全天）
阿里云百炼     ██████████            42% 的时间半价（22:00-08:00）
硅基流动       ██████                25% 的时间半价（仅 02:00-08:00）
```

**而教师在凌晨 2–8 点是睡觉的。** 所以硅基流动那个"半价"对师创基本用不上。

### 3.2 各平台定位建议

| 平台 | 在师创里的角色 | 理由 |
|---|---|---|
| **DeepSeek 官方** | **主力** | 半价窗口最宽（周末全天），缓存命中价最低（¥0.05/M），师创架构已设计"system 前缀逐字节稳定"来命中缓存 |
| **硅基流动** | **备份 + 多模型源** | 一个 API Key 调 DeepSeek/GLM/Kimi/Qwen/文心/混元/豆包，运维极简；新用户送 2000 万 token + 16 元代金券，首充翻倍（充1送1）；企业认证 95 折 |
| 阿里云百炼 | 企业合规备选 | 有发票、SLA、企业认证，适合学校采购走账；闲时窗口 10 小时尚可 |
| OpenRouter | ❌ 不用 | 虽便宜但**数据出境**，教育场景有合规风险 |

> 师创架构本来就是**多模型适配器**（DeepSeek 主 + 至少一家备份），所以这个组合天然成立：**官方直连跑主力省钱，硅基流动做备份和一个 Key 管全家。**

## 十、OPC 社区与 Token 补贴（⚠️ 含重要合规提醒）

### 10.1 OPC 是什么（不是技术平台！）

**OPC = One Person Company（一人公司）**：以大模型、智能体为核心技术驱动的**轻量型创业实体**。核心逻辑是"一人主体、AI 赋能、轻资产、低风险、快迭代"。

**OPC 社区**是各地政府为这类 AI 个体创业者建的**孵化空间 + 政策落地载体**，提供工位、算力/Token 补贴、人才公寓、金融服务、工商财税代办等。

> 截至 2026 年，全国已有 **20 个省份发布 106 项 OPC 专项政策**。广东（2026-03）是全国首个省级专项政策；深圳、杭州、安徽、雄安、成都等地均已落地。

### 10.3 ⚠️ 关键合规提醒：教师身份注册公司有限制

要享受 OPC 补贴，**必须先注册一家一人有限责任公司**并入驻社区。但野马是**在编教师**（事业单位工作人员），这里有明确限制：

| 依据 | 内容 |
|---|---|
| 《事业单位工作人员处分暂行规定》第十八条 | 违反国家规定从事、参与营利性活动或兼职取酬 → **警告/记过**；情节较重 → **降级/撤职**；情节严重 → **开除** |
| 邵阳市教育局答复 | 在职在编教师隶属事业单位非工勤人员，**参照《公务员法》管理，不得入股公司** |
| 颍上县政府答复 | 事业编教师注册个体工商户 → 属违规 |
| **人社部规〔2017〕4 号** | **支持和鼓励事业单位专业技术人员创新创业**——**按要求履行审批手续且依规依法从事的，不违规** |

**结论：不是绝对不行，但必须走审批。** 关键看三点：
1. 当地/本校是否有禁止性规定（如某省《实施〈义务教育法〉办法》）
2. 该经营活动是否与履职行为冲突（在自己管理服务的学校卖产品 → 明确禁止）
3. 是否履行了审批/报备手续

**强烈建议在注册公司之前，先向学校人事部门或当地教育局书面咨询确认。**
