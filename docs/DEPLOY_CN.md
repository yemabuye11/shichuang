# 师创 (ShiChuang) — 国内版部署迁移清单

> **版本**：v1.0
> **撰写日期**：2026-09-12
> **适用场景**：海外版跑通后，迁移到中国大陆合规部署
> **目标读者**：野马（非程序员）+ 协作工程师
> **前置依赖**：[海外版部署指南](./DEPLOY.md) 已完成并稳定运行 ≥ 1 个月

---

## 一、为什么需要国内版

| 原因 | 说明 |
|---|---|
| **访问速度** | 海外版（GitHub Pages + Supabase 新加坡）在中国大陆访问慢/不稳定 |
| **合规要求** | AI 生成内容涉及未成年人教育，国内需 ICP 备案、内容审核 |
| **模型 API** | 国内需用合规模型（DeepSeek 国内/通义/豆包），海外模型 API 不稳定 |
| **教材检索** | 国内教材需用合规搜索源，不能直接用境外搜索 API |

## 二、合规与备案清单

### 2.1 ICP 备案（必做）
- **主办者**：野马本人（个人）或师创公司（企业）
- **备案类型**：个人/企业 ICP 备案
- **审核时间**：个人 7–20 天，企业 10–25 天
- **办理入口**：[阿里云备案](https://beian.aliyun.com) 或 [腾讯云备案](https://console.cloud.tencent.com/beian)
- **所需材料**：身份证、网站负责人照片、域名证书、服务器接入商信息

### 2.2 公安联网备案（必做）
- 备案完成后 30 天内必须做
- 入口：[全国互联网安全管理服务平台](https://beian.mps.gov.cn)

### 2.3 教育类特殊要求
- **算法备案**（如使用生成式 AI 推荐/排序算法）：[国家网信办算法备案](https://beian.cac.gov.cn)
- **教师/学生数据**：涉及未成年人，需符合《个人信息保护法》《未成年人保护法》

> ⚠️ 建议：MVP 阶段先用海外版跑业务，备案完成后再切国内版。备案期间可同时用海外版获取种子用户。

## 三、域名与 CDN 选择

### 3.1 域名
- **推荐**：`.cn` 或 `.com.cn` 域名（国内备案快，信任度高）
- **服务商**：阿里云万网 / 腾讯云 DNSPod
- **首年费用**：约 ¥30–50

### 3.2 静态托管 + CDN（前端产物）

| 方案 | 优势 | 劣势 | 推荐度 |
|---|---|---|---|
| **阿里云 OSS + CDN** | 国内最快、备案友好、按量计费 | 配置稍复杂 | ⭐⭐⭐⭐⭐ |
| **腾讯云 COS + CDN** | 微信生态友好、备案快 | 同阿里云 | ⭐⭐⭐⭐⭐ |
| 七牛云 | 老牌、便宜 | 性能略弱 | ⭐⭐⭐ |
| 又拍云 | 联盟可返流量 | 知名度低 | ⭐⭐ |

**推荐**：阿里云 OSS + CDN（野马熟悉的生态）

#### 阿里云 OSS 配置步骤
1. 创建 Bucket：`shichuang-prod`，读权限公共读
2. 开启静态网站托管：默认首页 `index.html`，默认 404 `index.html`（SPA fallback）
3. 创建 CDN 加速域名：绑备案域名，开启 HTTPS（免费证书）
4. CDN 缓存策略：
   - `/assets/*` 缓存 1 年（带 hash 的静态资源）
   - `/index.html` 不缓存
   - `/a/*`、`/d/*` 缓存 1 天（产物 HTML）

### 3.3 后端服务（Supabase vs 国内替代）

| 方案 | 优势 | 劣势 | 推荐 |
|---|---|---|---|
| **继续用 Supabase 新加坡** | 零迁移成本；技术栈不变 | 访问慢；数据出境合规风险 | MVP 阶段 |
| **迁移到国内云数据库**（阿里云 RDS / 腾讯云 TDSQL） | 合规；速度快 | 需要重写部分 SQL/RLS | 规模化阶段 |
| **Supabase 自托管**（Docker 部署到国内云） | 技术栈一致 | 需要自维护 | 不推荐 |

**推荐路径**：
- **第一阶段**（0–3 个月）：继续用 Supabase 新加坡 + 国内 CDN 加速
- **第二阶段**（用户 > 1000）：评估迁移到国内云数据库

## 四、AI 模型 API 国内化

### 4.1 模型选型

| 模型 | 提供方 | 价格（输入/输出 元/百万 token） | 推荐度 |
|---|---|---|---|
| **DeepSeek-V3** | 深度求索 | 1–4 / 4–16 | ⭐⭐⭐⭐⭐（主力） |
| **通义千问 Qwen-Plus** | 阿里云 | 4 / 12 | ⭐⭐⭐⭐ |
| **豆包 Pro** | 字节火山引擎 | 0.8 / 2 | ⭐⭐⭐⭐（性价比） |
| 文心一言 | 百度 | 4 / 12 | ⭐⭐⭐ |
| 智谱 GLM-4 | 智谱 | 100 / 100 | ⭐⭐（贵） |

**推荐组合**：**DeepSeek-V3 主力 + 豆包 Pro 备份**（双适配器，热切换）

### 4.2 API Key 管理
- 每个客户（教师/管理员）独立申请 Key
- 在师创管理后台填写 Key（密钥加密存储，前端不展示）
- 国内版需要在管理后台增加"模型 API 配置"页面

### 4.3 内容审核（必做）
- 所有 AI 生成内容必须经过国内合规审核
- 推荐接入：阿里云内容安全 / 腾讯云天御
- 审核不通过的内容自动降级为"仅自己可见"，并提示教师

## 五、教材检索 API 国内化

### 5.1 合规搜索源

| 源 | 优势 | 劣势 | 推荐 |
|---|---|---|---|
| **国家中小学智慧教育平台 API** | 官方、权威、教材配套 | 覆盖不全，开放程度有限 | ⭐⭐⭐⭐⭐ |
| **人民教育出版社 API** | 教材最权威 | 仅人教版 | ⭐⭐⭐⭐ |
| **博库网 / 当当** | 教辅丰富 | 需付费 | ⭐⭐⭐ |
| **百度/搜狗学术搜索** | 覆盖广 | 内容混杂 | ⭐⭐（需人工筛选） |

**推荐**：先接入国家中小学智慧教育平台（如果开放 API），否则用百度学术搜索 + 教师核对。

### 5.2 实现路径
- 在 `_shared/search/` 目录加 `ChinaSearchAdapter`
- 替换 `TavilyAdapter` 为 `ChinaSearchAdapter`
- 配置切换：环境变量 `SEARCH_PROVIDER=china`

## 六、数据迁移（如果从 Supabase 迁到国内云）

### 6.1 评估指标
- 用户数 > 1000
- 月生成数 > 5000
- 月度访问 > 10 万 PV
- 出现数据合规审查需求

### 6.2 迁移步骤
1. **导出**：用 `pg_dump` 从 Supabase 导出全库
2. **导入**：导入到阿里云 RDS PostgreSQL
3. **代码改造**：
   - 替换 Supabase 客户端为直连 PostgreSQL（用 `postgres.js` 或类似）
   - 保留 Auth 逻辑（迁移到阿里云 IDaaS 或自建）
4. **Storage 迁移**：用 ossutil/coscli 同步 Bucket
5. **DNS 切换**：低峰期切换，保留 7 天回滚

### 6.3 不推荐的做法
- 不要在 MVP 阶段做迁移（成本不划算）
- 不要在用户量 < 100 时做（数据量小，重建比迁移快）

## 七、国内版部署步骤（简版）

### 步骤 1：备案 + 域名
- 完成 ICP 备案（约 7–20 天）
- 购买 `.cn` 域名

### 步骤 2：开通阿里云 OSS + CDN
- 创建 OSS Bucket，开启静态托管
- 创建 CDN 加速域名，配置 HTTPS
- 备案域名 CNAME 到 CDN

### 步骤 3：配置国内模型 API
- 申请 DeepSeek 国内 API Key
- 在师创管理后台配置（加密存储）

### 步骤 4：构建并部署前端
```bash
# 修改 .env.production 指向国内 CDN
VITE_SUPABASE_URL=https://xxxxx.supabase.co  # 暂用 Supabase 新加坡
VITE_API_BASE=https://api.shichuang.cn  # 国内 API 入口

# 构建
npm run build

# 上传到 OSS
ossutil cp -r dist/ oss://shichuang-prod/

# 刷新 CDN
ossutil refresh oss://shichuang-prod/ --cdn
```

### 步骤 5：验证
- [ ] 国内网络能正常打开
- [ ] 注册/登录正常
- [ ] 生成走国内模型 API
- [ ] AI 生成内容有合规审核
- [ ] 教材检索走国内源

## 九、时间表（**按需触发，非固定排期**）

> **野马拍板（2026-09-12）**：迁移**等客户量上来后再做**，不预设固定时间点；且**数据要跟着一起迁**（不是重建）。

### 迁移触发条件（满足任一即启动）

- 付费用户 > 500
- 月生成数 > 1 万
- 出现数据合规审查需求
- 国内访问体验成为明显瓶颈（教师投诉率上升）

### 阶段安排

| 阶段 | 触发时机 | 动作 |
|---|---|---|
| 海外版上线 | T+0（立即） | 海外版正式上线 GitHub Pages |
| **备案启动** | **T+0（同步，不要等！）** | 同步启动 ICP 备案（7–20 天审核，**备案免费，早办早省心**） |
| 国内云准备 | 触发后 | 开通阿里云 OSS+CDN，配置国内模型 API |
| 国内模型适配 | 触发后 | DeepSeek 国内/豆包适配器开发 |
| 内容审核接入 | 触发后 | 阿里云内容安全 SDK 接入 |
| 教材检索国内化 | 触发后 | 国家智慧教育平台 API 对接 |
| **数据迁移** | 触发后 | `pg_dump` 导出 → 导入国内云 → Storage 同步 → **校验完整性**，数据整体跟着走 |
| 国内版灰度 | 触发后 +7 天 | 10% 流量切国内，监控稳定性 |
| 国内版全量 | 触发后 +14 天 | 全量切换，海外版保留 7 天做备份 |

### 三条关键原则

1. **备案一定要早做**：审核要 7–20 天且免费，不要等触发条件满足才开始，否则会白等一个月
2. **数据跟着迁，不是重建**：用户账号、生成历史、沉淀的教材知识、Skill 库、内容沉淀库全部迁移过去，教师**不需要重新注册、历史内容不丢**
3. **海外版保留兜底**：全量切换后海外版保留 7 天，出问题可秒切回

## 十、风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 备案被驳回 | 中 | 提前准备材料；选择备案通过率高的接入商 |
| 内容审核误杀 | 中 | 人工复核机制；教师可申诉 |
| 模型 API 不稳定 | 低 | 双适配器（DeepSeek + 豆包），自动切换 |
| 数据出境合规 | 中 | MVP 阶段用 Supabase 新加坡可豁免；规模化后必须迁国内 |
| 国内 CDN 成本超支 | 低 | 监控用量；超过预算自动降级（关非核心功能） |
